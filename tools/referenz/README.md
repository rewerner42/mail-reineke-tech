# Reference generator (verification tool)

The Python original of the report generator, kept as an independent second
implementation. It is **not** part of the Worker and never runs in production —
Cloudflare Workers cannot run Python, and the report is generated by
`src/report/`. This tool exists to check that port and to calibrate the layout:

- **View model oracle.** `generator/render.py` builds the view model from a
  signal file. `tests/viewmodel-equivalence.test.ts` compares our TypeScript
  output against the frozen results it produced.
- **Overflow check and page counts.** It renders the template with headless
  Chrome and reports, per page, whether any element crosses the print margin.
  The template estimates page breaks from character counts, so every catalogue
  change has to be re-rendered — this is how the target page counts are set.
- **Structure check.** `pruefung/pruefe_struktur.py` and
  `pruefung/inhalt_pruefen.py` inspect the rendered HTML.

## Running it

Needs Python 3.10+, jinja2, pillow, Google Chrome and poppler (`pdfinfo`,
`pdftoppm`). Chrome and poppler come from the system; the Python packages are
best kept in a throwaway virtual environment:

```
python3 -m venv /tmp/v15 && /tmp/v15/bin/pip install jinja2 pillow
/tmp/v15/bin/python tools/referenz/generator/render.py tools/referenz/vorlage --ausgabe out
```

Add `--signale tools/referenz/generator/daten/stresstest` for the edge cases, or
`--nur-pruefen` to run the overflow check without writing files.

`ASSETS_DIR` overrides where images are read from (default: `public/assets`).
